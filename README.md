# Woodly-ProgettoTSW

Piattaforma e-commerce responsive dedicata alla vendita di mobili e complementi d'arredo realizzati interamente in legno. Il progetto è sviluppato per offrire un'esperienza d'acquisto fluida sia da desktop che da smartphone, coprendo due esigenze di mercato principali:



\## 🚀 Funzionalità Chiave



\* \*\*Catalogo Ready-to-Use:\*\* Prodotti pronti (sedie, tavoli, librerie) per un acquisto rapido e immediato.

\* \*\*Arredamento Su Misura:\*\* Servizio personalizzato per la progettazione di mobili destinati all'ottimizzazione degli spazi degli utenti.

\* \*\*Design Mobile-First \& Responsive:\*\* Interfaccia flessibile per garantire un'ottima navigazione da qualsiasi dispositivo.
